# 00. Обзор продукта

## Идея
Пользователь находит книгу, видит цены во всех магазинах Казахстана на одном экране и может поставить «маячок»: письмо придёт, когда цена упадёт до нужной.

Рабочее название — **KitapRadar**. Проект учебный, некоммерческий.

## Персоны
| Персона | Задача | Что важно |
|---|---|---|
| Студент | Купить книгу по программе | Самая низкая цена, наличие |
| Читатель со списком «хочу прочитать» | Дождаться скидки | Маячок, не пропустить снижение |
| Покупатель подарка | Купить быстро | Наличие, доставка, красивое издание |
| Администратор | Следить за системой | Парсеры, очереди, почта, статистика |

## Ключевые понятия
| Понятие | Значение |
|---|---|
| **Книга (book)** | Произведение: «Мастер и Маргарита», автор Булгаков |
| **Издание (edition)** | Конкретное издание книги: ISBN, издательство, год, переплёт, язык. **Цены сравниваются внутри издания.** |
| **Магазин (store)** | Kaspi.kz, Flip.kz, Meloman, Wildberries, Ozon |
| **Предложение (offer)** | Издание в конкретном магазине: цена, старая цена, наличие, ссылка |
| **История цены** | Запись создаётся только когда цена предложения изменилась |
| **Маячок (beacon)** | Подписка пользователя на издание с условием: любое снижение / ниже X ₸ / скидка от N% |
| **Запуск парсера (parser run)** | Один проход парсера по магазину: время, успех, ошибки |

## Функции по версиям

### MVP (Фаза 2 + 3)
- Поиск по названию, автору, ISBN; нечёткий поиск; подсказки
- Фильтры: магазины, цена, наличие, переплёт, язык; сортировка
- Карточка: издания, лучшая цена, таблица магазинов, история цены, оценка «ниже/выше средней»
- Реальный сбор цен из 5 магазинов по расписанию и по запросу (через очередь)
- Регистрация с подтверждением email, вход, refresh-токены, сброс пароля
- Маячки: 3 типа условий, пауза, удаление; email при срабатывании; отписка в один клик; режим «сводка раз в день»
- Админ-панель: KPI, здоровье сервисов, парсеры, очереди, журнал, топ запросов

### v2 (Фаза 4, по желанию)
- Kafka для потока событий цен (практика + аналитика)
- Telegram-бот как второй канал уведомлений
- ИИ: импорт списка книг из текста, помощь в сопоставлении изданий, рекомендации
- Учёт стоимости доставки, выбор города

## Принятые решения (по умолчанию, можно пересмотреть)
| Вопрос | Решение для MVP |
|---|---|
| База проекта | Репозиторий `book-price-aggregator`, продолжаем историю вех |
| Парсеры | Java-модуль внутри backend (Jsoup + Playwright for Java) |
| Брокер | RabbitMQ (Kafka — v2), см. [ADR-001](adr/ADR-001-rabbitmq.md) |
| Frontend | React + Vite + TypeScript, UI строго по макетам `docs/frontend/mockups/` (26 экранов), поведение — `docs/frontend/SCREENS.md` |
| Цена с доставкой? | Нет. Сравниваем цену товара, доставку показываем текстом от магазина |
| Выбор города | Нет. Цены и доставка — как магазин показывает для Алматы/по умолчанию |
| ИИ в MVP | Нет. Только в v2 |
| Telegram | v2 |
| Форматы | Только бумажные книги. Электронные и аудио — не в MVP |
| Google Books | Только источник метаданных (обложка, описание, ISBN). **Цену не даёт** |
| Избранное | Заменяется маячками. Старый API `/api/favorites` удаляется вместе с переходом фронтенда (F3) |
| Валюта | Только KZT. Цены Ozon/WB берём в тенге, как сайт показывает для Казахстана |

## Метрики успеха проекта (для портфолио)
- Реальные цены минимум из 3 магазинов из 5
- Поиск отвечает быстрее 200 мс (p95) при тёплом кэше
- Письмо по маячку приходит не позже следующего цикла парсинга
- Покрытие тестами сервисного слоя ≥ 70%
- Запуск всего проекта одной командой `docker compose up`
