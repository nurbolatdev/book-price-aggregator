# ADR-003: Модель «книга → издание → предложение»

**Статус:** принято · **Дата:** 2026-10-20

## Контекст
В Фазе 1 предложения магазинов привязаны прямо к книге. Но одна книга продаётся в разных изданиях (твёрдый переплёт за 3 600 ₸ и мягкая обложка за 1 900 ₸). Сравнивать их цены — нечестно, а пользователь хочет конкретное издание.

## Решение
Три уровня: `books` (произведение) → `editions` (ISBN, издательство, год, переплёт, язык) → `offers` (издание в магазине). Цены, история и маячки — на уровне **издания**. Сопоставление предложения с изданием — по ISBN, иначе нечёткое сравнение названия/автора с ручной проверкой спорных случаев.

## Последствия
- (+) Честное сравнение цен, понятный UI выбора издания.
- (+) ISBN — естественный ключ для сопоставления между магазинами.
- (−) Сложнее сопоставление, когда магазин не показывает ISBN → статус `PENDING_REVIEW` и ручная привязка в админке.
- (−) Миграция данных Фазы 1 (V5–V7).
