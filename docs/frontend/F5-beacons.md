# F5 — Маячки

**Ветка:** `feature/f5-beacons` · **Зависит от:** F4 · **Оценка:** 2–3 дня

## Цель
Главная функция продукта: поставить маячок из поиска или карточки, управлять маячками на «Моих маячках», отключить маячок по ссылке из письма. Все изменения — мгновенно (оптимистично) с откатом при ошибке. Макеты 04, 05, 13, 26.

## Перед началом прочитать
`docs/frontend/SCREENS.md` — экраны 04, 05, 13; макеты `04-beacon-modal`, `05-beacons`, `26-beacons-mobile`, `13-unsubscribe`, `15-states`; `docs/03-api-contract.md` — раздел 4 (маячки); `docs/backend/M19-beacons-notifications.md` (как срабатывает маячок — для текстов).

## Задачи

### 1. Данные — `features/beacons/`
- [ ] `useBeacons()` — `GET /beacons` (весь список), ключ `queryKeys.beacons`.
- [ ] Мутации `createBeacon`, `updateBeacon` (условие или статус), `deleteBeacon` — оптимистично в кэше `beacons` и `beacons.byEdition(id)`, откат и toast при ошибке, `invalidate` после ответа.
- [ ] `CONFLICT` при создании → toast «На эту книгу маячок уже стоит» со ссылкой «Изменить» → `/beacons`.

### 2. Окно маячка — `BeaconModal` (макет 04)
- [ ] Открывается из карточки издания (F3: «Следить за ценой», `?beacon=1`), из результатов поиска (колокольчик, F2) и с «Моих маячков» («Изменить условие»). Режимы: создание и изменение (заголовок и кнопка меняются: «Поставить маячок» / «Сохранить»).
- [ ] Книга: обложка, название, `label` издания, «Сейчас от {bestPrice}».
- [ ] «Когда сообщить»: `ANY_DROP` «При любом снижении»; `BELOW_PRICE` + поле цены (по умолчанию лучшая цена −10 %, округление до 10 ₸; цена должна быть ниже текущей — иначе подсказка под полем); `DISCOUNT_PERCENT` + поле 1–90 % (по умолчанию 15). Поле показывается только у выбранного варианта.
- [ ] «Куда отправить»: «Email: {email}» отмечен и неактивен; «Telegram — скоро» неактивен.
- [ ] Почта не подтверждена → жёлтая плашка «Почта не подтверждена — маячок сохранится, но письма придут после подтверждения» + «Отправить письмо ещё раз».
- [ ] Доступность: `role="dialog"`, `aria-labelledby`, фокус в первое поле, Esc/«Отмена» закрывают, фокус возвращается; телефон — нижняя панель (`Sheet`).
- [ ] После создания — toast «Маячок поставлен · Мои маячки», кнопка на карточке меняется на «Маячок стоит · изменить».

### 3. «Мои маячки» `/beacons` — макеты 05 и 26
- [ ] Вкладки «Все · Сработали · Ждут · На паузе» с числами, фильтрация на клиенте, выбранная вкладка в URL (`?tab=`).
- [ ] Сработавшие (`TRIGGERED`) — сверху, выделенная карточка: «Сработал {сегодня/вчера/дата} в {время}», цель и текущая цена с магазином, «Купить за {цена}» (`currentBestUrl`, новая вкладка), «Следить дальше» (`PATCH {status: ACTIVE}`).
- [ ] Строка маячка: обложка, название → `/editions/{id}`, автор, «Цель: любое снижение / ниже X ₸ / скидка от N%», «Сейчас лучшая {цена}» + подпись по типу условия (`SCREENS.md` экран 05), плашка статуса, кнопки «Изменить условие», «Пауза»/«Возобновить», «Удалить» (иконки с `aria-label`).
- [ ] Пауза/возобновление — оптимистично; подпись «пауза с {дата}» из `statusChangedAt`.
- [ ] Удаление: карточка исчезает сразу, toast «Маячок удалён · Отменить» 5 с; `DELETE` отправляется после закрытия toast без «Отменить»; уход со страницы до закрытия — отправить сразу.
- [ ] Правая колонка: `NotificationSettings` (из F4) и «Как работает маячок» со ссылкой на `/settings`; на телефоне — под списком (макет 26).
- [ ] Пусто — `EmptyState` (макет 15): «Маячков пока нет» + «Найти книгу» → `/catalog`; загрузка — 3 скелетона строки.

### 4. Отключение из письма `/unsubscribe?token=` — макет 13
- [ ] **При загрузке запрос не отправлять** (почтовые сканеры открывают ссылки). Кнопка «Поставить маячок на паузу» → `POST /beacons/unsubscribe {token}` → «Маячок на паузе» + «Все маячки» (`/beacons`, вход при необходимости). Ошибка токена — «Ссылка недействительна».
- [ ] Страница работает без входа.

### 5. Снимки
