# F3 — Карточка издания

**Ветка:** `feature/f3-edition` · **Зависит от:** F2 · **Оценка:** 2–3 дня

## Цель
Главный экран продукта: все цены одного издания, лучшая цена, история цены, другие издания и похожие книги. Десктоп — макет 03, телефон — макет 07 с нижней панелью.

## Перед началом прочитать
`docs/frontend/SCREENS.md` — экран «03 · Карточка издания · 07 · телефон» и §1; макеты `03-book`, `07-book-mobile`, `15-states`; `docs/03-api-contract.md` — `GET /editions/{id}` (ответ), `/editions/{id}/price-history`, `/editions/{id}/similar`, `GET /books/{id}`, `GET /beacons?editionId=`.

## Задачи

### 1. Данные — `features/edition/`
- [ ] `useEdition(id)` — `GET /editions/{id}`, `staleTime` 5 мин; prefetch уже вызывается из поиска (F2).
- [ ] `usePriceHistory(id, period)` — `GET /editions/{id}/price-history?period=1M|3M|6M`, по умолчанию `3M`.
- [ ] `useSimilar(id)` — `GET /editions/{id}/similar?limit=4`, `staleTime` 1 ч.
- [ ] `useBeaconForEdition(id)` — только для вошедшего: `GET /beacons?editionId=`.
- [ ] `/books/:id` — `GET /books/{id}` и `replace`-редирект на издание с лучшей ценой.

### 2. Страница `/editions/:id` — `pages/EditionPage.tsx` (макет 03)
- [ ] Хлебные крошки: «Главная / Поиск «{q}» / {title}», если пришли из поиска (ссылка ведёт на тот же URL поиска), иначе «Главная / {title}».
- [ ] Левая часть: обложка (`Cover`, 260×380), название (`font-display`), автор, кнопки «Издание» (текущее `aria-pressed`, остальные из `otherEditions` → `/editions/{id}` без перезагрузки страницы), ISBN/Страниц/Язык (пустые строки скрыты), описание со сворачиванием после 4 строк и «Читать полностью».
- [ ] Правая карточка «Лучшая цена сейчас»: цена, «{магазин} · в наличии · доставка …», плашка `priceVerdict` (правила — `SCREENS.md` §1), «Перейти в {магазин}» (`target=_blank rel="noopener noreferrer"`), «Следить за ценой» (гость → `/login?returnTo=/editions/{id}?beacon=1`; есть маячок → «Маячок стоит · изменить»; иначе — окно маячка из F5; до F5 — ссылка на `/beacons`), строка «Обновлено N ч назад…» (максимум `lastSeenAt`).
- [ ] `?beacon=1` в URL открывает окно маячка при загрузке (после F5) и убирает параметр из адреса.
- [ ] Таблица «Цены в N магазинах»: сортировка по цене, лучшая строка — фон `best-row`, колонки Магазин / Цена / Было / Доставка / Наличие / Обновлено / «В магазин»; нет в наличии — внизу списка.
- [ ] «История минимальной цены»: переключатель 1/3/6 мес, Минимум/Средняя/Максимум, линейный график. **Recharts загружается лениво** (`React.lazy` для компонента графика, отдельный чанк); пока грузится — скелетон высотой графика. Мало точек (< 2) — текст «История появится после нескольких проверок цены».
- [ ] «Похожие книги»: до 4 карточек (название, автор, «от {price}») → `/editions/{editionId}`; пусто — блок не показывать.
- [ ] `<title>`: «{title} — цены в магазинах Казахстана | KitapRadar»; `meta description` с лучшей ценой.

### 3. Телефон — макет 07
- [ ] Шапка «назад» + «Поделиться» (Web Share API; нет — копировать ссылку и toast «Ссылка скопирована»).
- [ ] Цены списком карточек (лучшая — зелёная рамка), история и похожие ниже.
- [ ] **Нижняя панель всегда видна**: лучшая цена + «Следить» + «Купить»; высота кнопок ≥ 48 px; учесть `env(safe-area-inset-bottom)`; контент страницы не перекрывается панелью.

### 4. Состояния
- [ ] Скелетон всей страницы с теми же размерами блоков; 404 → `NotFound`; ошибка — `ErrorBlock` с «Повторить»; ошибка истории или похожих — только на месте блока.
